# Assignment 1 – Namma Metro Smart-Card Fare System

This folder contains all 12 tasks from Assignment 1, including the Day-4 Design Challenge.

## Folder guide

- Task-1 to Task-3: object-oriented analysis, tokens/constants and data types.
- Task-4 to Task-5: conversion and operator precedence predictions, with C++ programs.
- Task-6: pseudocode and completed fare logic.
- Task-7: procedural and object-oriented implementations.
- Task-8: safe input and formatted output.
- Task-9: table-driven fare tests and boundary checks.
- Task-10: scale and numeric-type comparison.
- Task-11: final design recommendation.
- Task-12: revised four-zone, weekend-discount and monthly-pass design.

## Compile and run

Open a terminal in the required task folder. For example:

```bash
g++ -std=c++17 -Wall -Wextra Task6.cpp -o Task6
./Task6
```

On Windows Command Prompt:

```bat
g++ -std=c++17 -Wall -Wextra Task6.cpp -o Task6.exe
Task6.exe
```

Use the matching source filename for each task. The source files are independent programs and should be compiled separately.

## Important assumptions

The assignment mentions student and senior-citizen concessions but does not specify the concession percentages or application order. No percentage has been invented in the original-design tasks; the policy must be confirmed with the metro authority. The Task-12 example follows the new rule that the weekend discount replaces, rather than combines with, peak surcharge.

Before submission, run every program on your own compiler, capture actual screenshots/output, and add your name, register number and compiler version to the repository README.
